# Python API на Flask

**Формат:** учебное приложение «Крестики-нолики» с HTTP API.

**Исходный проект:** `AP1_Py_T05B_ID_1421510-1/src`.

## Что сделано

- Разделил код на веб-слой, сервисы предметной области, модели и слой доступа к данным.
- Использовал Flask для HTTP-маршрутов и SQLAlchemy для хранения пользователей и игр.
- Добавил регистрацию и вход с хешированием паролей; реализовал выдачу access и refresh JWT.
- Написал тесты для авторизации и получения истории завершённых игр.

## Что показывает работа

Понимание структуры веб-приложения, зависимостей сервиса и того, какие компоненты потребуется конфигурировать и сопровождать при развёртывании.

## Примеры кода

- [Работа с играми через SQLAlchemy](python-game-repository.py): сохранение, выборка завершённых игр и расчёт рейтинга.
- [Выдача и проверка JWT](python-jwt-provider.py).
- [Тесты истории игр, рейтинга и авторизации](python-test-game-history.py) с SQLite в памяти.

Файлы взяты из одного учебного приложения без изменения логики. Они используют другие модули проекта и не запускаются по отдельности. Тестовый JWT-ключ и пароли в файле тестов являются фикстурами.

## Границы

В исходном приложении есть локальные настройки и отладочные сообщения. Эти фрагменты демонстрируют реализацию, но не являются подготовленной к production публикацией всего сервиса.
