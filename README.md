## О проектах

Работы выполнены в рамках учебных заданий «Школы 21». Примеры кода Python взяты из более крупного приложения и отдельно не запускаются. Скриншоты сетевого стенда находятся на внешнем хостинге, как в исходном отчёте. Я не приписываю себе разработку учебных постановок задач и не заявляю опыт с Kubernetes, Terraform или production CI/CD, которого эти работы не подтверждают.
