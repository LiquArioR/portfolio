# Антон — начинающий DevOps-инженер

Практикуюсь в Linux, сетях, PostgreSQL и Python. Ниже — выполненные учебные проекты и конкретные задачи, которые я решал. Это учебная практика, а не опыт эксплуатации production-систем.

## Проекты

| Проект | Что сделано | Навыки |
| --- | --- | --- |
| [Сети в Linux](linux-networking.md) | Настройка адресации и маршрутов на виртуальных машинах; проверка связности и пропускной способности; правила `iptables`, DHCP, NAT и SSH-туннели | Linux, TCP/IP, netplan, `iproute2`, `tcpdump`, `iperf3`, `iptables`, DHCP, SSH |

| [Python API на Flask](python-api.md) | Учебное веб-приложение с разделением на слои, хранением данных через SQLAlchemy и JWT-авторизацией | Python, Flask, SQLAlchemy, PostgreSQL, JWT, тестирование |

## О проектах

Работы выполнены в рамках учебных заданий «Школы 21». В карточках указаны исходные локальные проекты и границы того, что я проверил. Я не приписываю себе разработку учебных постановок задач и не заявляю опыт с Kubernetes, Terraform или production CI/CD, которого эти работы не подтверждают.
