# Сетевой стенд: фрагменты выполненного отчёта

Источник: `DO2_LinuxNetwork.ID_356275-1/src/Report.md`. Лаборатория использовала рабочие станции `ws11`, `ws21`, `ws22` и маршрутизаторы `r1`, `r2`. Ниже приведены команды, настройки и результаты, записанные в исходном отчёте. Это учебный стенд, а не готовая production-конфигурация.

## Адресация и маршрутизация

Для проверки принадлежности адресов к сети в отчёте применялся `ipcalc`. Затем на хостах были настроены статические маршруты через netplan и проверена связность после перезагрузки. При построении схемы с двумя маршрутизаторами использовались `ip r`, `ping`, `traceroute` и захват ICMP-пакетов:

```sh
tcpdump -n -i enp0s3 icmp
```

По записи в отчёте, `tcpdump` на `r2` показывал пакеты от `ws11`; для недоступной сети был разобран ответ ICMP «Destination Network Unreachable».

## Пропускная способность и правила фильтрации

На одной машине запускался сервер `iperf3`, с другой выполнялось подключение:

```sh
iperf3 -c 192.168.100.10
```

В разделе `iptables` проверялся порядок правил для ICMP: запрещающее правило перед разрешающим блокировало ответ, обратный порядок пропускал его. Доступность узлов дополнительно проверялась `nmap -sn`.

## DHCP и NAT

В исходном отчёте зафиксирована выдача адресов `ws21` и `ws22` из диапазона `10.20.0.2–10.20.0.50` сервером DHCP на `r2`. На `r1` выполнялась привязка адреса `ws11` к MAC. Использовались опции `range`, `option routers`, `option domain-name-servers`, `hardware ethernet`, `fixed-address`.

Для NAT на `r2` применялся скрипт с правилами фильтрации, SNAT и DNAT. Проверка HTTP-сервиса на `r1` из `ws22` в отчёте записана так:

```text
telnet 10.100.0.11 80
GET / HTTP/1.0
Host: 10.100.0.11
```

В ответ получена HTML-страница Apache. Для DNAT зафиксировано подключение с `r1` к сервису `ws22` через `r2:8080`.

## SSH-туннель

Apache на `ws22` слушал `localhost:80`. Из `ws21` использовался локальный проброс порта:

```text
-L 8080:localhost:80
```

В отчёте указан адрес SSH-хоста `ab@10.20.0.3` и проверка обращения к локальному порту `8080`. Эти фрагменты отражают сделанную лабораторную работу; старые ссылки на её скриншоты больше не показывают оригинальные изображения.
