# PostgreSQL: индексы и целостность данных

**Формат:** учебные SQL-задания на PostgreSQL.

**Исходные проекты:** `SQLB7_Database_index_ID_574093-1`, `SQLB8_Integrating_features_ID_574095-1`, `SQLB9_OLAP_ID_574096-1`, `SQLB10_Isolation_levels_ID_574106-1`.

## Что сделано

- Создал индексы по внешним ключам, функциональный индекс по `UPPER(name)`, составные и частичные индексы.
- Использовал `EXPLAIN ANALYZE`, чтобы смотреть план выполнения запросов с индексами.
- Описал таблицу персональных скидок с первичным и внешними ключами, проверками допустимых значений и уникальностью пары «пользователь — пиццерия».
- Заполнил таблицу через `INSERT ... SELECT`, добавил последовательность для идентификаторов и комментарии к схеме.
- Написал запросы с `JOIN`, группировкой, агрегатами и оконными функциями.
- Выполнил учебный сценарий с двумя сессиями и `COMMIT` для изучения видимости изменений.

## Что показывает работа

Понимание структуры реляционной БД, базовых способов проверки плана запроса и обеспечения целостности данных. Это полезно при сопровождении приложений и разборе проблем с БД.
