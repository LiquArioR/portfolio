# Антон — начинающий DevOps-инженер

Практикуюсь в Linux, сетях, PostgreSQL и Python. Самостоятельно разворачиваю сервисы на VPS, а ниже показываю выполненные проекты и конкретные задачи, которые решал.

## Практический опыт на VPS

- **Собственный VPN.** Самостоятельно развернул VPN на VPS: подготовил Linux-сервер, настроил сетевой сервис и проверил подключения.
- **Telegram-бот.** Развернул Telegram-бота на VPS: подготовил окружение, запустил приложение и проверил его работу.

Этот опыт дал мне практику удалённого администрирования Linux-сервера, работы по SSH, настройки сетевых сервисов и диагностики их доступности.
